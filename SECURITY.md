# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a security problem.
Report it privately through [GitHub's private vulnerability reporting](https://github.com/DanielChahine0/Shore-Up/security/advisories/new).

Include the steps to reproduce it and the impact you expect.
You will get a reply within a week.

## Scope

- The Shore Up web app and its API routes.
- The Supabase schema and Row Level Security policies in `supabase/migrations/`.
- Image upload handling in `lib/images/`.

## Supported versions

Only the latest commit on `main` is supported.
